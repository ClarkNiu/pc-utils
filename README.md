## 中文

### 项目概述
pc-utils 是一个开源项目，提供各种实用的 PC 工具脚本，帮助用户解决常见的计算机问题。这些脚本轻量级、无需安装、免费使用。

### 工具列表

#### Windows 文件夹强制删除 (windows_folder_force_delete)
用于强制删除被系统锁定或权限不足无法删除的文件和文件夹。支持递归删除、自动获取权限等功能。

- **文件**: `force-delete.bat`, `force-delete.ps1`
- **适用系统**: Windows 7/8/10/11
- **详细说明**: [查看子目录 README](windows_folder_force_delete/README.md)

## English

### Project Overview
pc-utils is an open-source project that provides various practical PC tool scripts to help users solve common computer problems. These scripts are lightweight, require no installation, and are free to use.

### Tools List

#### Windows Folder Force Delete (windows_folder_force_delete)
A script to force delete files and folders that are locked by the system or have insufficient permissions. Supports recursive deletion, automatic permission acquisition, and more.

- **Files**: `force-delete.bat`, `force-delete.ps1`
- **Supported Systems**: Windows 7/8/10/11
- **Detailed Instructions**: [View subdirectory README](windows_folder_force_delete/README.md)

### Installation and Usage
1. Download or clone this repository
2. Navigate to the respective tool directory
3. Follow the instructions in each tool's README
